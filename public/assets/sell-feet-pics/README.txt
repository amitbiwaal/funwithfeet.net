NOTES
------------------------------------------------------
- .jpg extension is what the page expects. If you upload .webp or .png,
  update the <img src="..."> paths in /sell-feet-pics/index.html to match.
- Squares are cropped with object-fit:cover, so keep the subject centred.
- Keep each file under ~200 KB so the page stays fast.
- All images must be non-explicit and you must have the rights to use them.
- Alt text is already written in the HTML; adjust it if your image differs
  from the description above.
